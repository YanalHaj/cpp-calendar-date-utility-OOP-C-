# C++ Date & Calendar Utility Library (`clsDate`)

A robust, header-only C++ date manipulation and calendar management utility. This library provides functional capabilities for date arithmetic, calendar rendering, business day calculations, and date comparisons using OOP standards.

---

## Key Features

- **Date Arithmetic**: Add/subtract days, weeks, months, years, decades, and centuries.
- **Calendar Generation**: Print full month or year calendars to the console.
- **Workday & Vacation Tracking**: Calculate net business days, weekend detection, and dynamic vacation return dates.
- **Date Comparison**: Compare relative ordering (`Before`, `Equal`, `After`) and compute accurate difference in days between two dates.
- **System Time Integration**: Automatically fetch and process current system date metrics.
